E5: live readings vs reference device

Read before quoting a number

  1. The deep models are rPPG-Toolbox's released checkpoints. A fine-tune on UBFC gave no gain, so nothing trained for this project beats them yet.
  2. UBFC is indoor, still and uncompressed. Real webcam video will give larger errors.
  3. TS-CAN trained on SCAMPS transfers poorly to UBFC. This was checked with 5 scoring methods, including the toolbox's own, so it is not a scoring mistake.
  4. Robustness to movement and light (E3), skin-tone bands (E4) and the live comparison with a reference device (E5) need volunteer recordings and have no results yet.
